[도서 리뷰] 바이브 코딩을 위한 안티그래비티 2.0

9월 23, 2026 · 4 분

알림

한빛미디어 서평단 <나는리뷰어다> 활동을 위해 도서를 협찬받아 작성된 서평입니다.

최근 IT 도서 시장에는 AI 도구를 활용한 개발 서적이 앞다투어 출간되고 있습니다. 클로드, 제미나이, 챗GPT 등 LLM이 점차 개발의 표준 도구로 자리 잡는 추세입니다.

저 또한 지금은 실무에서 제미나이를 보조 도구로 활용해 코딩을 진행하고 있기에, 안티그래비티 기반의 ‘바이브 코딩’ 실전 가이드를 명확히 제시하는 이번 도서 리뷰에 참여하게 되었습니다

기술의 발전 속도가 워낙 빠르다 보니 트렌드를 쫓는 것조차 쉽지 않은 요즘입니다. 이 책은 클론 코딩 프로젝트를 통해 바이브 코딩을 어떻게 적용하는지 구체적으로 안내해 줍니다.

총 3가지의 실전 프로젝트를 따라가다 보면 바이브 코딩이라는 새로운 개발 방식에 한층 더 친숙해질 수 있습니다.

전반적으로 이 책은 AI를 통해 쉽고 빠르게 결과물을 도출하는 방법에 집중하고 있기는 한 것 같습니다.
그렇지만 저자는 책 초반부에 단순히 AI에 의존하기보다 코드를 읽는 힘과 서비스의 동작 원리를 이해하고, 주도적으로 문제를 고민하고 해결하려는 습관이 결국 성장의 핵심이라는 점을 분명히 강조합니다.

1부. 바이브 코딩할 결심#

1부에서는 안티그래비티(Anti-gravity) 2.0에 대한 기본적인 개념과 함께, 본격적인 바이브 코딩을 위한 개발 환경 및 툴 초기 설정 방법을 다룹니다.

2부. 나만의 링크 모음 페이지 (with 스킬)#

첫 프로젝트로 링크 모음 페이지를 만듭니다. 여기서 가장 강조하는 것은 역시 프롬프트를 얼마나 잘 작성하는가입니다.

코딩에 익숙하지 않은 독자도 무리 없이 따라올 수 있도록, 특정 기술이나 언어부터 접근하는 대신 기능 중심으로 차근차근 개발을 진행합니다. 한 번에 하나의 기능씩 완성해 나가는 점진적인 접근이 핵심입니다.

개인적으로 권장하는 팁으로 Git과 같은 버전 관리 시스템을 적극 활용하는 것입니다.
AI가 작성한 코드를 바로 반영하기보다 커밋(commit) 단위로 비교해 보고, 의도와 다르게 작성되었다면 언제든 revert 할 수 있는 안전망을 갖추는 것이 좋습니다. AI가 엉뚱한 코드를 생성하더라도 최악의 상황은 면할 수 있기 때문이죠.

마지막으로 작업의 지침서 역할을 하는 스킬(Skill)의 개념을 다룹니다. SKILL.md, AGENTS.md, DESIGN.md 와 같은 문서를 프로젝트 기반에 깔아두면, AI가 어떤 규칙과 방식으로 작업해야 하는지 가이드라인을 제시할 수 있어 훨씬 효율적입니다.

3부. 최저가 알림 봇 (with 스킬, 하네스, API)#

두 번째 프로젝트에서는 폴센트와 유사한 최저가 알림 봇을 만듭니다. 여기서 본격적으로 스킬(Skill)을 활용합니다.

스킬은 에이전트가 특정 도메인이나 작업을 수행할 수 있도록 지시사항과 도구 사용법을 패키지화한 것입니다.
복잡한 명령어를 묶어두거나 외부 API 사용법을 미리 정의하면 AI가 일관성 있고 정확하게 동작하도록 돕는 기능입니다.

책에서는 K-Skill Github를 통해 네이버 쇼핑 최저가 검색 스킬 등을 적용하는 방법을 안내합니다.
국내 환경에 맞는 유용한 스킬들이 오픈소스로 공유되고 있다는 점이 매우 흥미로웠습니다.

또한 하네스 엔지니어링(Harness Engineering)의 개념도 등장합니다.

하네스(Harness)는 본래 말의 힘과 방향을 제어하는 고삐를 뜻합니다.

AI 코딩에서 하네스란 AI에게 지시를 내리는 과정 전체가 아니라, AI가 짠 코드가 엉뚱하게 작동하지 않도록 안전하게 검증하는 ‘테스트 환경이나 안전장치’를 의미합니다.

따라서 책에서 AI가 구현한 본 코드를 바로 실전에 투입하지 않고, 이를 검증하기 위해 테스트용 파이썬 스크립트를 추가로 요청해 실행해 본 것이 바로 하네스를 구축한 대표적인 예시라고 볼 수 있습니다.

이후 카카오톡 메시지 API와 안티그래비티 스케줄러, 깃허브 액션(GitHub Actions)을 활용해 특정 시간에 알림 봇을 자동 실행하는 방법까지 안내합니다.

4부. 중고 거래 서비스 (with 멀티 에이전트, MCP, 배포)#

마지막으로 당근마켓과 같은 중고 거래 서비스의 핵심 기능을 구현합니다. 정적인 데이터와 동적으로 쌓이는 데이터를 어떻게 구분하고 관리할지 설계하는 것부터 시작합니다.

이 프로젝트에서는 멀티 에이전트(Multi-Agent)에 대해 알려줍니다. 여러 역할을 가진 서브 에이전트들에게 프롬프트로 지시를 내려 웹사이트를 협업하여 구축합니다.

클로드에서는 서브에이전트를 명시적으로 지정했던 것 같았습니다.
그런데 안티그래비티에서는 프롬프트만으로 유연하게 에이전트들을 다룰 수 있더라구요.

이후 Supabase(수파베이스)를 이용한 데이터베이스 연동과 로그인 기능 구현을 다룹니다.
아무래도 책에서는 AI의 도움을 받으니 복잡한 DB 스키마 구성이나 인증 기능도 순식간에 완성됩니다. 마지막으로 Vercel(버셀)을 통해 완성된 프로젝트를 세상에 배포하는 것으로 책의 내용은 마무리됐네요.

이제는 모르는게 있어도 AI 끈질기게 붙잡고 하면 정말 뭐든 만들 수 있지 않을까 라는 생각이 듭니다.

느낀 점#

이 책은 개발자가 아닌 일반인을 대상으로 하고 있는 것 같아 가볍게 읽기 좋은 것 같습니다.

이제는 누구나 아이디어와 실행력만 있다면 AI의 도움을 받아 번듯한 서비스를 만들어낼 수 있을 것 같아요. 최근 이 책과 유사한 강의나 도서를 여럿 접해보았는데, 전체적인 흐름과 지향점은 모두 동일했던 것 같습니다.

아무리 뛰어난 도구가 있어도, 결국 그것을 쥐고 서비스를 만들어내는 것은 온전히 사람의 몫이라는 생각이 듭니다. 저 역시 퇴근 후 일정한 루틴을 만들고자 매번 다짐하지만, 막상 집에 돌아오면 쉬기 바빴는데요. 이제는 AI의 도움을 조금 빌려서라도 제 아이디어를 실제 서비스로 하나씩 구현해 봐야겠습니다

도서에서 알려준 유용한 사이트#

  • skillsmp: 다양한 스킬을 정리해둔 사이트
  • K 스킬: 국내에서 쓸 수 있는 스킬 모음 github
  • 당근 디자인 시스템: 당근 디자인 포맷을 확인할 수 있는 사이트
